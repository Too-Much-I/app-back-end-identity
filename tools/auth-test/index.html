Identity 인증 테스트

로컬 전용 · Google + 가상 전화번호 · 테스트 서버만 사용

실제 테스트 계정/세션이 생성됩니다. 토큰은 메모리에만 보관하며 새로고침하면 사라집니다. 화면·네트워크 정보를 공유하지 마세요. Android SDK 검증은 별도입니다.

1. Firebase 웹 설정

프로젝트 설정 → 내 앱 → 웹 앱의 Firebase 구성 객체를 JSON으로 입력하세요. 서비스 계정 JSON은 넣지 마세요.

프로젝트는 to-teacher-firebase로 제한됩니다. localhost 허용 도메인 설정이 필요할 수 있습니다.

2. Google 로그인 · 가입 준비

3. 같은 계정에 테스트 전화번호 연결

콘솔에 등록된 가상 번호와 고정 코드를 사용합니다. 실제 SMS 발송은 지원하지 않습니다.

4. Identity 회원가입

배포 담당자가 확인한 현재 정책 버전을 입력하고 해당 약관을 읽은 뒤 직접 동의하세요. 버전은 자동 추정하지 않습니다.

5. 서버 인증 확인

자동 재시도 없음. 재발급 응답 유실 시 이 도구는 세션을 버리고 다시 로그인하도록 합니다(Stage 9 복구 테스트 도구가 아닙니다). 로컬 삭제는 서버 세션 폐기가 아닙니다.

6. SMS 계정 찾기 (가상 번호 전용)

기존 로그인은 보존합니다. 같은 Firebase 프로젝트의 별도 메모리 인증 세션으로 SNS·마스킹 이메일만 안내합니다. 회원 로그인이나 Guest 병합을 실행하지 않습니다.
