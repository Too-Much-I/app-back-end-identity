# 계정·학습 기록 삭제 정책 권장안

## 1. 5줄 결론

1. 2026-10-08 사용자 요청에 따른 정책 권장값이며 현재 운영 보장 또는 법률 검토 완료를 의미하지 않는다.
2. 본인 확인된 탈퇴 요청 수락 시 Identity 이용·재발급을 차단하고 일반 계정 프로필을 제거한다.
3. Firebase·SNS 연결 정리는 24시간 목표, 학습·음성·전사·채점 삭제는 7일 목표, 일반 삭제의 최대 처리 기준은 30일을 권장한다.
4. 사용자 요청으로 중복 혜택 방지용 전화번호 HMAC과 최소 탈퇴·동의 증빙의 보관 기준을 모두 탈퇴일부터 3년으로 변경한다.
5. 위 기한에 맞는 파기·감시·백업 정책과 학습 서버 연동을 구현·검증한 후 공개한다.

## 2. 사용자가 반드시 읽어야 하는 내용

| 대상 | 권장 처리·기산점 | 목적/주의 |
|---|---|---|
| 닉네임·이메일·설치 해시·비밀번호 해시 | 인증된 탈퇴 요청을 수락하는 트랜잭션에서 제거 | 기존 tombstone 방식과 호환 |
| Firebase 사용자·SNS 연결·마스킹 이메일 | 수락 후 24시간 내 목표, 최대30일 | SNS 제공자 계정 자체 삭제 아님 |
| 학습 기록·음성·전사·채점 결과 및 파생 사본 | 수락 후7일 내 목표, 최대30일 | LC·파일·캐시·외부 처리업체 범위 확인 필요; 학습 품질 검토 동의 자료도 원칙적으로 포함 |
| 전화번호 HMAC·최소 혜택 사용 여부 | 탈퇴일부터3년 후 파기 | 재가입 자체 차단이 아닌 반복 혜택 악용 방지; 번호 원문·이메일·프로필을 함께 남기지 않음 |
| 최소 탈퇴·동의 증빙 | 탈퇴일부터3년 후 파기 | 처리 이력·분쟁 대응; 내부 ID, 동의 항목/버전/시각, 요청/완료 시각으로 최소화 |
| Firebase UID가 든 작업 이력 | 정리 완료 후30일 이내 UID 제거 또는 레코드 삭제 | 최소 처리 증빙으로 전환, 실패 건도30일 초과 방치하지 않음 |
| 기존 인증 세션·응답 캐시 | 요청 수락 시 사용 불가, 수락 후30일 내 잔존 데이터 파기 | TTL 만료만으로 사용 차단을 대신하지 않음 |
| 일반 운영·보안 로그 | 생성일부터30일 | 토큰/전화/이메일 등 민감 원문 로깅 금지; 법적 의무 적용 여부 별도 검토 |
| 이메일 삭제 요청의 추가 본인 확인 자료 | 처리 완료일부터30일 내 파기 | 토큰·비밀번호·신분증 사본을 기본 수집하지 않음 |
| 백업 | 생성일부터 최대30일 순환 만료 | 삭제 전 마지막 백업도 요청 후30일 내 만료되도록 설계; 복원 시 삭제 목록 재적용 |

이 값은 법정 의무기간이 아닌 제품 정책 기준이다. 사용자 요청으로 정한 3년 보관의 법적 근거·필요성·비례성은 개인정보 담당자가 검토해야 하며, 법률상 보존 의무가 확인된 특정 거래/민원 기록은 항목별 근거·기간으로 별도 관리한다. 실제 결제·거래 존재를 확인하지 않고 모든 기록을5년 보관한다고 선언하지 않는다.

## 3. 사용자가 결정해야 하는 사항

- 기본 정책안은 위 값으로 정한다. 다만 전화번호당 평생1회 혜택 정책과 3년 후 HMAC 파기는 양립하지 않으므로 혜택 정책 담당자와 조정해야 한다. 타 서버의 식별값을 무기한 남겨3년 고지를 우회하지 않는다.
- 이메일 접수는 요청 채널이며 자체 인증이 아니다. 앱 없이 이용할 수 있는 웹 SNS 인증 또는 SMS 소유 확인 + 기존 계정 연계·위험 점검을 마련한다. 번호 단독 제출/마스킹 이메일 일치만으로 삭제하지 않는다. 확인 후 수락부터 처리 기한을 계산하고 접수·보완 안내는2영업일 내 목표로 한다.
- 비회원은 유효 Guest 인증으로 기록 소유자를 확인한다. 모든 학습 기록 삭제는 계정 유지가 기본이며, Guest 계정 삭제는 별도 명시한다. 인증 상실 시 임의 설치 ID만으로 다른 기록을 삭제하지 않는다.

## 4. 주요 위험과 미확인 사항

- 최대30일은 아직 시스템이 보장하지 않는 제안이다. 완료 추적, 24시간 지연 경보, 운영자 조치와 기한 준수 절차가 필요하다. 오류시 무기한 보존 대신 개인정보 담당자에게 이관한다.
- 과거 모델 학습에 이미 반영된 데이터 처리·외부 서비스·파일 버전·백업은 별도 확인한다. 재식별 가능한 가명 자료를 익명 통계로 간주하지 않는다.
- 법정 예외·분쟁 보존은 사유별 최소 항목에 한정하고 접근 격리·보존 종료 후 파기한다. 자동 연장하지 않는다.

## 5. 현재 작업과 직접 관련된 설명

이번 변경은 문서뿐이다. 실제 DB/파기 코드/배포 설정은 변경하지 않았다. 기존 코드의 정리 주기5초나 세션 기본14일은 이 정책의 최대 완료 시간을 보장하지 않는다. Firebase 정리 완료와 LC 학습 삭제 완료를 별도로 추적해야 한다.
